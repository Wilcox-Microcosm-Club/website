# Officer Guide

## Publish an announcement

1. Open the website and select **Officer login** in the footer.
2. Sign in with your individual officer account.
3. Select **New announcement**.
4. Add a title and body.
5. Optionally upload one JPG, PNG, or WebP image no larger than 5 MB.
6. Select **Save draft** to keep it private or **Publish** to make it public immediately.

## Edit or delete an announcement

Open the officer dashboard, select the pencil beside the announcement, make the change, and publish it again. Use Delete only when the announcement should be permanently removed.

## Account rules

- Do not share passwords.
- Each officer should use an individual account.
- Remove access when an officer leaves the team.
- Never paste a Supabase secret key into GitHub, Cloudflare, or the website.
