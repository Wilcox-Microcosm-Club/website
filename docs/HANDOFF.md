# Web Manager Handoff

Complete this checklist before the current Web Manager leaves office.

- Confirm the club controls the Gmail account and recovery methods.
- Confirm the domain has current billing and recovery information.
- Add the incoming Web Manager to GitHub, Cloudflare, and Supabase.
- Make the incoming Web Manager an administrator in the website's `profiles` table.
- Have the incoming Web Manager publish, edit, and delete a test announcement.
- Review Cloudflare deployment history and Supabase backups/settings together.
- Confirm at least two trusted people can recover the club Gmail.
- Remove the former Web Manager's website, GitHub, Cloudflare, and Supabase access.

Normal posting does not require editing code. A developer is only needed for redesigns, new features, or repairing an unusual infrastructure problem.
